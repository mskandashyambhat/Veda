# Veda v0.3 10K Experiment

This run keeps the validated v0.3 architecture and frozen 32K BPE tokenizer unchanged.

- Steps: `10,000`
- Micro-batch: `2`
- Gradient accumulation: `16`
- Effective batch: `32`
- Warmup: `500` steps
- AdamW learning rate: `3e-4`
- Minimum learning rate: `3e-5`
- Validation: every 500 steps, 20 batches
- Checkpoints: `checkpoints/veda-v0.3-10k/`
- Metrics: `experiments/v0.3-10k/metrics.jsonl`

The final report will be completed after the run exits and will include the full learning curve, best checkpoint, training time, throughput, and fixed-prompt generations.
